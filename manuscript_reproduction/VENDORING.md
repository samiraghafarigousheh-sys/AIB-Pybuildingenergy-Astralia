# Source provenance

The root `pybuildingenergy/` directory in this reproduction package is **modified** source. It must not be described as a verbatim upstream copy.

The original thermal source is retained separately under `original/pybuildingenergy/src/`. Its project baseline commit is `2e6e910c1297ff3e88bad3184a4f1e74e1a93815`, with upstream ancestry recorded as `1236ace2fcc54f570cc4e7686b6fa3c1fa8b0573`.

`revision_results/COMPLETE.json` records hashes for the executed revised Python files and main runner. `stage1_results/COMPLETE.json` additionally records the original source, attribution scripts and relevant inputs. `verify_release.py` checks them directly. Retain `pybuildingenergy/LICENSE.md` and source copyright headers.

The superseded provenance note from the original archive described an earlier, unmodified vendor import. Its blanket statement that the revised directory was unmodified was no longer accurate and has been replaced here.
